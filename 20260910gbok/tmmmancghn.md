## 一、行前评估：我到底适不适合赴美？

先给结论：PGT-A并非"万能钥匙"，它解决的是"胚胎染色体异常"这一核心痛点。以下4类人群收益最大：

- 女方年龄≥35岁，且AMH>1.0 ng/mL，预计可取出≥6枚卵子

- 经历过2次以上不明原因流产

- 多次移植优质胚胎仍未着床

- 一方有染色体结构异常（平衡易位、倒位）家族史

评估工具：国内任意一家三甲医院生殖中心完成"生育力初筛套餐"即可，包括：

项目女方男方参考区间

激素六项月经第2-3天—FSH<10 IU/L，E2 20-80 pg/mL
AMH任意时间—1.0-4.0 ng/mL为佳
阴道B超月经第2-3天—AFC（基础窦卵泡）≥8枚
精液分析—禁欲2-7天总量≥1.5 mL，前向运动≥32%
染色体核型双方双方46,XX/46,XY
传染病八项双方双方HIV、梅毒、乙肝、丙肝

拿到报告后，扫描件发至INCINTA中文病历部，48小时内会得到Dr. Lin团队的"书面评估+视频会诊"双回执。若AMH<0.8 ng/mL，医生会提前告知"可能需要双周期卵子"，避免第一次赴美空手而归。

## 二、首诊与促排方案：中美两地如何无缝衔接

1. 预约节奏：建议月经周期前2周完成视频面诊，确定用药方案。

2. 药物来源：美国FDA批准药（Gonal-F、Menopur、Cetrotide）可在北京/上海/广州指定药房自提，也可到加州后由INCINTA药房直配，价格差异<8%。

3. 促排方案：35岁以下、AFC≥12枚，常规采用"拮抗剂方案"；38岁以上或FSH>12 IU/L，倾向"微刺激+双周期"，降低卵巢过度刺激（OHSS）风险。

4. 远程监测：国内三甲医院做B超+抽血，数据上传至INCINTA专属APP，Dr. Lin每2天调整一次剂量。平均用药9-12天，当主导卵泡≥18 mm、E2≥200 pg/mL/枚时，即可订机票。

## 三、赴美卵子与实验室操作：14天行程表

Day1（月经第1天）→ 国内起飞，直飞洛杉矶LAX，入住托伦斯公寓（距诊所8分钟车程）。

Day2 → 上午到INCINTA抽血+B超，确认卵泡同步；下午领取夜针（HCG或Lupron trigger）。

Day3 → 休息+观光，可前往 nearby 的Del Amo购物中心调整时差。

Day4 → 卵子手术（IV Sedation，15分钟），术后1小时可步行回公寓。Dr. Lin平均获卵12-14枚。

Day5 → 受精：常规IVF或ICSI，根据男方精子活力决定。

Day6-10 → 胚胎培养至囊胚（Blastocyst）阶段，INCINTA采用"连续时差成像（Time-lapse）"系统，每10分钟拍照，AI算法优选出扩张最快、碎片最少的胚胎。

Day11 → 胚胎活检：从囊胚滋养层取5-8个细胞，送PGT-A检测；胚胎立即玻璃化冷冻。

Day12 → 回国：携带Dr. Lin签字的"促排总结报告"，方便后续内膜准备。

Day14 → 月经恢复（通常比自然月经提前2-3天），国内继续用药。

## 四、PGT-A检测与胚胎结果解读：数字背后的真正含义

INCINTA与加州两家CAP认证实验室合作，平均15个自然日出报告。报告核心指标：

术语中文释义临床意义

Euploid整倍体推荐优先移植，活产率60-65%
Mosaic嵌合体20-40%可健康分娩，需结合嵌合比例
Aneuploid非整倍体不建议移植，流产率>85%
No result检测失败可二次活检或弃用

常见误区：

- "整倍体=100%成功"——仍受内膜、免疫、血栓前状态影响

- "嵌合体一定畸形"——低比例（<30%）嵌合，产后随访多数正常

- "PGT-A会损伤胚胎"——滋养层取样不影响内细胞团，玻璃化复苏率>98%

## 五、内膜准备与冷冻移植：第二次赴美3周就够

1. 人工周期：国内月经第2天开始口服Estrace 4-6 mg/日，第12天B超内膜≥8 mm、三线征清晰，即可订机票。

2. 到美后：INCINTA复查内膜+抽血（E2>200 pg/mL，P<1 ng/mL），开始黄体支持——阴道凝胶Crinone 8%+每日肌注Progesterone 50 mg。

3. 移植日：Dr. Lin采用"软导管+超声引导"法，5分钟完成，术后卧床30分钟即可回公寓。

4. 验孕：移植后第9天抽血β-HCG，≥50 IU/L为阳性；第11天翻倍≥120 IU/L提示胚胎活力良好。

5. 胎心：移植后第28天B超见孕囊+心管搏动，即可毕业转产科。

## 六、孕后管理与双程回国：产科衔接、证件办理

1. 美国产科：INCINTA与UCLA Health、Hoag Hospital均签绿色转诊协议，孕12周可直接预约NT+无创DNA。

2. 回国时机：建议选择孕28-32周，航空公司要求"产检证明+风险评估"。

3. 证件：宝宝出生后，托伦斯市府3天可出出生纸，2周拿到美国护照+中国旅行证，全程INCINTA配备中文助理陪同。

4. 国内落户：持"出生纸+领事馆认证+翻译件"到父母户籍所在地派出所，可正常落户，不违反任何现行法规。
