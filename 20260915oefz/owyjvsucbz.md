# 如何判断卵巢功能

> 更新时间：2026-09-15 (UTC+8)

判断卵巢功能可通过amh检测、性激素六项检查、超声检查、基础体温测定、卵巢活检等。

1. amh检测：即抗缪勒氏管激素检测，它能较为准确地反映卵巢储备功能。该指标不受月经周期影响，随时可检测。数值越高，代表卵巢储备的卵泡数量越多；数值越低，提示卵巢功能可能在衰退。一般来说，正常范围在2-6.8ng/ml ，若低于1.1ng/ml，卵巢储备功能可能下降；小于0.086ng/ml，提示卵巢功能衰竭。

2. 性激素六项检查：包含促卵泡生成素、促黄体生成素、雌二醇、孕酮、睾酮、泌乳素。通常在月经来潮第2-4天进行检测，了解基础内分泌状态。其中，促卵泡生成素升高，尤其大于10IU/L，提示卵巢储备功能可能降低；若大于40IU/L，且雌二醇水平低下，则高度怀疑卵巢功能衰竭。

3. 超声检查：通过B超观察卵巢大小、形态及窦卵泡数量。卵巢大小随年龄增长逐渐变小，窦卵泡数量是评估卵巢功能的重要指标。一般双侧卵巢窦卵泡数小于6个，提示卵巢储备功能下降。经阴道超声检查能更清晰地观察卵巢情况，为判断提供更准确依据。

4. 基础体温测定：女性在排卵后，由于孕激素作用，体温会升高0.3-0.5℃ ，形成双相体温曲线。若基础体温曲线呈单相，无体温升高变化，可能提示无排卵，间接反映卵巢功能异常。需连续测量至少3个月经周期，且测量要规范，如清晨醒来未进行任何活动时测量。

5. 卵巢活检：属于有创检查，相对较少使用。通过获取卵巢组织进行病理检查，直接观察卵巢的组织结构和卵泡发育情况。能准确判断卵巢是否存在病变及功能状态，但因有一定风险，如出血、感染等，通常在其他检查无法明确诊断时才考虑。

进行相关检查时，要选择正规医院，确保检查结果的准确性。检查前遵循医生的指示做好准备，如某些检查需空腹、避开月经期等。若检查发现卵巢功能异常，应积极配合医生进一步诊断和治疗，制定个性化方案。
